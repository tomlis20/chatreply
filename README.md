# ChatReply

Reply to chat messages with quoted context, Discord/Slack-style, for World of Warcraft.

- [CurseForge](https://www.curseforge.com/wow/addons/chatreply)
- Supports Retail and WoW Forever (classic beta, interface 16001)

## Slash commands

- `/reply` or `/rr` — reply to the last message received
- `/reply <name>` — reply to the last message from a specific player
- `/reply on` / `off` — enable/disable the addon
- `/reply links` — toggle the clickable [Reply] link in chat
- `/reply embed` — toggle embedding the quote in the sent message text (visible to non-addon users)
